СУФЛЁР ДУБЛЯЖА — Android-приложение 1.4.0 (WebView-оболочка)

Приложение спрашивает адрес REAPER (IP:порт) один раз и открывает http://IP:порт/prompter.html.
Реплики, позиция и сдвиг видео берутся из REAPER (см. README сборки установщика).
Экран: сверху видео, посередине кнопки, снизу субтитры.

ЧТО НОВОГО В 1.4.0
- Повторяющиеся ошибки страницы в «Диагностике» сворачиваются в одну строку со счётчиком («×5»).
- Диалог диагностики больше не может вызвать сбой, если экран уже закрыт.
- WebView: доступ к файлам устройства закрыт (страница берётся только по сети).
- «Загрузка видео при запуске» исправлена на стороне страницы (она обновляется из REAPER сама).

ЧТО НОВОГО В 1.3.0
- Кнопки громкости сразу меняют громкость мультимедиа (раньше на Android они меняли громкость звонка, пока
  не заиграет медиа). В «Диагностике» показана громкость мультимедиа и предупреждение, если она равна нулю.
- Сервер видео в отчёте «Диагностика» показывает звуковые дорожки файла (кодеки).

ЧТО НОВОГО В 1.2.0
- Быстрая проверка связи перед загрузкой (4 секунды): вместо долгого ожидания приложение сразу пишет причину:
  нет ответа (брандмауэр, другая сеть, неверный IP), соединение отклонено (порт/веб-интерфейс), 404, пароль.
- «Диагностика» (кнопка на экране ошибки и пункт в меню системной кнопки «Назад»): проверяет веб-интерфейс REAPER
  (/_/TRANSPORT), страницу суфлёра и сервер видео (порт 8765), показывает версии приложения, Android и WebView
  и последние ошибки страницы. Кнопка «Копировать» кладёт отчёт в буфер обмена — его можно прислать разработчику.
- Если Android убил процесс WebView (нехватка памяти при загрузке видео), приложение не вылетает, а перезапускает страницу.
- В отладочной сборке включена отладка WebView через chrome://inspect.

ВИДЕО
- Кнопка «Выбрать видео» на странице открывает системный выбор файла (video/*). Файл воспроизводится
  на телефоне и синхронизируется с курсором REAPER. После перезапуска приложения файл нужно выбрать снова.
- Лучше лёгкая копия mp4 H.264 без звука (звук идёт из REAPER).

СБОРКА APK
1. Android Studio (Meerkat 2024.3.2 или новее), JDK 17. File -> Open -> эта папка.
2. Дождаться Gradle Sync (скачает Gradle 8.11.1 и AGP 8.9.1; нужен интернет).
3. Build -> Build Bundle(s)/APK(s) -> Build APK(s). Файл: app/build/outputs/apk/debug/app-debug.apk
   (в папке нет gradlew — Android Studio обходится wrapper.properties; для консоли выполните `gradle wrapper`).

GOOGLE PLAY
- Build -> Generate Signed Bundle / APK -> Android App Bundle, свой keystore. targetSdk = 36.
- Нужна политика конфиденциальности (приложение ничего не собирает; в анкете Data safety — «нет данных»).
- android:usesCleartextTraffic="true" обязателен: REAPER отдаёт страницу по http:// в локальной сети.
  Network Security Config не умеет диапазоны IP, поэтому разрешён весь cleartext — укажите это в пояснении для ревью.
- При переходе на targetSdk 37 добавьте разрешение ACCESS_LOCAL_NETWORK и запросите его при запуске
  (доступ к локальной сети в Android 17 закрыт по умолчанию).

УПРАВЛЕНИЕ
- Кнопка «Назад» системы: изменить адрес / выйти.
- При ошибке экран показывает причину и сам повторяет подключение каждые 3 секунды.
- Экран не гаснет, системные панели скрыты.

Версия 1.4.0 (versionCode 5). 1.1.0: выбор видео-файла (WebChromeClient.onShowFileChooser), клавиатура закрывается при подключении.

ПРОВЕРЕНО: код компилируется компилятором Java против заглушек Android API (проверяет синтаксис, типы и
импорты, но не настоящие сигнатуры Android); разбор адреса и описания ошибок — 13 проверок; сетевая функция
проверки связи — на живом сервере (200, 404, отказ, зависший сервер).
НЕ ПРОВЕРЕНО: сборка в Android Studio и запуск на телефоне (нет Android SDK). Подсказки Studio «Project update»
(AGP 8.9.1) и «Gradle toolchain» можно игнорировать: на сборку они не влияют.
